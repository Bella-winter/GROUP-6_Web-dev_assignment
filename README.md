# GROUP-6_Web-dev_assignment
📁 Portfolio Website Recreation
📜 Project Overview
This project is a recreation of a provided portfolio website design using HTML, CSS, and optionally Bootstrap for styling and responsiveness.
The goal was to match the design as closely as possible, ensuring clean structure, good UI/UX, and responsive behavior across different devices.

🚀 Technologies Used
HTML5

CSS3

Bootstrap 5 (optional, used for responsiveness and quicker layout setup)

🎯 Solution Approach
HTML Structure: Built a semantic and organized HTML5 structure, separating different sections clearly (navbar, hero section, portfolio items, contact form, etc.).

CSS Styling: Applied custom styles to replicate the design closely. Focused on margins, paddings, fonts, colors, and layouts.

Bootstrap: Utilized Bootstrap classes where necessary to enhance responsiveness, grid layouts, and pre-designed components (like buttons or navbars).

Responsiveness: Ensured that the website adapts well to mobile, tablet, and desktop screen sizes using media queries and Bootstrap’s grid system.
